01 / วิถีโค้งคือสมการโพรเจกไทล์และสปินลูกบาส

การชู้ตลูกบาสเกตบอลแต่ละครั้งคำนวณด้วยสมการการเคลื่อนที่แบบโพรเจกไทล์ 3 มิติ y(t) = y₀ + vᵧt - ½gt² ทุก 1/60 วินาที โดยความสูงของห่วงมาตรฐานอยู่ที่ 3.05 เมตร และเส้นผ่านศูนย์กลางห่วง 45 ซม. มุมปล่อยบอลที่เหมาะสมที่สุด (Optimal Launch Angle) อยู่ระหว่าง 48°–52° เพื่อเปิดพื้นที่หน้าตัดวงรีของห่วงให้กว้างที่สุดขณะลูกบาสตกเข้าหาแป้น

ลูกบาสหมุนกลับหลัง (Backspin ω ≈ -8 rad/s) ขณะลอยในอากาศ เมื่อกระทบขอบห่วงหรือแป้นบาส แรงเสียดทานจะดูดกลืนพลังงานจลน์แนวราบ ทำให้ลูกบาสแฉลบลงห่วงอย่างนุ่มนวล (Shooter's Touch) แทนที่จะกระดอนออกแรงเกินไป

02 / การกระโดดชู้ตคือจลนศาสตร์ ไม่ใช่แอนิเมชันล่วงหน้า

เมื่อผู้เล่นพ้นพื้นสนาม จุดศูนย์กลางมวลเคลื่อนที่ด้วยความเร็วต้นแนวตั้ง v₀ ส่วนแขนและขาหมุนรอบข้อต่อจริงทุกเฟรม นักกีฬาปล่อยลูกบาสที่จุดสูงสุดของการกระโดด (Apex) ซึ่งความเร็วแนวดิ่งเป็นศูนย์ชั่วขณะ ทำให้ลดความคลาดเคลื่อนของแรงส่งและเพิ่มความแม่นยำในการชู้ตระยะ 3 แต้มและลูกโทษ

ในโหมด ดวลชู้ตลูกโทษ (Free Throw) ความคลาดเคลื่อนของจังหวะปล่อยมือนอกโซนสมดุล (หน่วยมิลลิวินาที) จะแปลงเป็นเวกเตอร์เบี่ยงเบนแนวราบ Δx, Δz ที่กำหนดว่าลูกจะลงกลางห่วงแบบ Swish หรือกระทบขอบเหล็ก

03 / กลยุทธ์ทีม 5v5, 3v3 และบรรยากาศสนาม

สนามแบ่งออกเป็นสนามมาตรฐาน 28 เมตรสำหรับเกม 5 ต่อ 5 และคอร์ทสตรีทด้านข้างสำหรับเกม 3 ต่อ 3 นักกีฬาฝ่ายรุกเคลื่อนที่ทำทางแบบไร้บอล (Off-ball Motion) เพื่อเปิดช่องส่งบอล ขณะที่ฝ่ายรับคำนวณตำแหน่งยืนปิดมุมระหว่างผู้ถือบอลกับห่วง (Help-side Defense)

ผู้ชมรอบอัฒจันทร์และหน้าร้านขายของว่างจะหันศีรษะติดตามตำแหน่งลูกบาสแบบเรียลไทม์ พร้อมแสดง คำพูดเชียร์ (Speech Bubbles) และกระโดดดีใจเมื่อเกิดจังหวะทำแต้มสำคัญหรือเข้าสู่พิธีมอบถ้วยรางวัลเมื่อครบ 3 นาที
